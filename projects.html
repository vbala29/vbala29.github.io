Parallex — Crowdsourced Distributed Computing Platform

Python · JavaScript · Ray · RabbitMQ · gRPC · MongoDB · Express.js · Electron
  • Co-architected a peer-to-peer compute marketplace where participants monetize idle machines by executing users' distributed jobs.
  • Implemented a scheduler provisioning ephemeral Ray clusters, matching jobs to volunteer nodes by CPU, RAM, and locality.
  • Built a RabbitMQ control plane for cluster formation and teardown, detecting node failures via periodic gRPC heartbeats.

Peer-to-Peer File Sharing System

C++14 · Pthreads · Distributed Hash Tables

PennOS — A Unix-Like Operating System

C · Linux · ucontext
  • Built a Unix-like operating system in C that runs on top of Linux, including PennShell — a shell with built-ins for redirection, piping, process creation/management, and file system access.
  • Implemented a kernel with a partial implementation of the POSIX API using the ucontext library for multithreading, plus a FAT filesystem with a user-level API for creating files/executables, managing permissions, and renaming/moving files.

SPLAT — Projectile Locating and Aiming Turret

C · Atmega328p · Python/OpenCV
  • Inspired by real missile defense systems, employed a computer vision based approach to projectile tracking, using a laser mounted on a servo-motor controlled turret to "engage" projectiles.
  • Included an LCD radar display and a remote command website for monitoring turret metrics and control.

Satellite-Based Flight Radar

C++/Arduino · Atmega328p · Java
  • Given the 2020 FAA mandate of ADS-B transponders in most U.S. aircraft, designed a flight radar system that uses ADS-B satellite data to display live information about nearby aircraft.
  • Consists of data retrieval software (Java), as well as a hardware display with stepper-actuated gauges, an I²C LCD display, and buttons controlled by two Atmega328p microcontrollers (C++/ArduinoIDE).
